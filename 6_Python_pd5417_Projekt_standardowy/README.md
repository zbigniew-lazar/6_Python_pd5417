# 6_Python_pd5417_Projekt_standardowy

Projekt końcowy z przedmiotu Podstawy programowania w języku Python.

Program analizuje krótkie sekwencje DNA drożdży. W przykładach pojawiają się nazwy genów związanych z metabolizmem cukrów, np. HXK1, HXK2, GLK1 i RAG5.

## Pliki

- `main.py` - program
- `sekwencje.txt` - sekwencje DNA w formacie FASTA
- `opis_programu.txt` - opis programu prostym językiem
- `requirements.txt` - potrzebne biblioteki

## Uruchomienie

```bash
pip install -r requirements.txt
python main.py
```

## Wyniki

Program tworzy pliki CSV i trzy wykresy PNG.
